# 원하는 포즈로 이미지 만드는 도구

## 도구 설명
- 사람 사진 한 장에서 관절(뼈대)을 뽑고, 그 관절 정보를 조건으로 넣어 **같은 자세의 다른 인물**을 만듭니다.
- 사용 모델: Stable Diffusion 1.5 + OpenPose ControlNet (`lllyasviel/sd-controlnet-openpose`)
- 라이선스 확인 (Hugging Face 모델 페이지 기준)
  - Stable Diffusion 1.5: `creativeml-openrail-m` (CreativeML OpenRAIL-M). 모델 카드에 사용 제한 항목이 있고, 제품에 쓰려면 추가 안전장치가 필요하다고 적혀 있습니다.
  - OpenPose ControlNet: `openrail` (모델 카드에서 CreativeML OpenRAIL-M 계열이라고 설명)
  - 이 저장소는 수업 과제(학습) 목적으로만 사용했습니다.

## 사용법
1. GitHub의 `pose_tool.ipynb`를 Colab에서 엽니다. (Colab → 파일 → 노트 업로드)
2. **런타임 → 런타임 유형 변경 → T4 GPU**로 바꿉니다.
3. 셀을 위에서부터 순서대로 실행합니다: 설치 → 모델 로드 → 포즈 추출(사진 업로드) → 이미지 생성 → 결과 저장.
4. `samples/`에서 참조 사진의 뼈대와 결과 이미지를 확인합니다.

## 테스트 결과
시드 42, 스텝 20으로 고정하고 한 가지씩만 바꿔 비교했습니다.

**같은 프롬프트, 다른 포즈**

| 번호 | 포즈 | 프롬프트 | 결과 |
|---|---|---|---|
| 1 | 뼈대에 사람 세 명이 잡힌 달리는 자세 (`pose_01.png`) | A factory worker in a white safety helmet … | 안전모를 쓴 사람이 세 명 나왔고 달리는 자세를 따라옴. 프롬프트는 한 명이었지만 인원수는 뼈대를 따라감 (`output_01.png`) |
| 2 | 양반다리로 앉은 자세 (`pose_02.png`) | 같은 프롬프트 | 앉은 자세와 손을 모은 모습이 같게 나옴. 손은 단순하게 뭉쳐 보임 (`output_02.png`) |

**같은 포즈, 다른 프롬프트** (공장 작업자 / 우주비행사 / 요리사)
- 세 경우 모두 자세는 유지되었고, 인물과 옷, 조명, 그림 느낌만 바뀌었습니다.
- 손과 손가락이 뭉쳐 보이는 문제는 프롬프트를 바꿔도 계속 나타났습니다.
- 자세한 표는 `pose_tool.ipynb` 마지막의 실험 기록에 있습니다. 프롬프트는 `prompts.md`에 있습니다.

## 한계
- **손과 손가락**: 모든 실험에서 부정확하고 관절이 뭉쳐 보였습니다. OpenPose 뼈대에는 손가락 정보가 없어서 그런 것으로 추측합니다.
- **발목과 발**: 일부 결과에서 발목과 발이 떨어져 보였습니다.
- **인원수**: 뼈대에 사람이 여러 명이면 프롬프트에 한 명이라고 써도 여러 명이 나옵니다.
- 참조 사진은 몸 전체가 또렷하게 보여야 뼈대가 잘 뽑힙니다.

## 폴더 구성
- `pose_tool.ipynb`: Colab 튜토리얼 노트
- `samples/`: 참조 포즈 이미지와 결과 이미지
- `prompts.md`: 테스트에 쓴 프롬프트
